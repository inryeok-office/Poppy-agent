## 3. 결론과 남은 확인

- **yaw 부호 `+1` 검증됨.** `TURN RIGHT` → `vyaw` 음수 → 시계 방향. `POPPY_PHYSICAL_TURN_LEFT_YAW_SIGN=+1` 유지.
- MOVE 전·후진, TURN 좌·우, 자세(SIT → STAND) 후 MOVE 가 모두 SDK 응답 성공으로 끝났고 모든
  MOVE/TURN 뒤 `StopMove` 3회가 성공했다. 결과 불명(Unknown) 실행은 없었다.
- SIT 뒤 STAND 를 `StandUp → BalanceStand` 로 보냈을 때 SDK 는 성공을 돌려줬다. 물리적으로 정상
  기립했는지는 운영자 관찰 기록이 따로 없어 **미검증**으로 남긴다. r7 부터는 SDK 예제
  (`sport_client_example.py:72`, `:81`)를 따라 SIT 직후 STAND 를 `RiseSit` 으로 보낸다 — r7 첫
  시연 때 기립 동작을 관찰해 이 문서에 추가한다.
- PRESET(인사·하트·춤·스트레칭)은 이 Agent journal 구간에 실행 이벤트가 없다. 운영자 보고("일부
  동작")와 차이가 있어 r7 시연 때 다시 기록한다.
